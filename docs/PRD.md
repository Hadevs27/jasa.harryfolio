# Product Requirements Document (PRD)

## 1. Overview
Harnad Technologies adalah static landing page yang berfungsi untuk menawarkan jasa solusi digital dan bantuan akademik (academic assistance, web development, mobile development, technical assistance).

## 2. Target Audience
- Mahasiswa yang membutuhkan bantuan akademik (makalah, skripsi, project akhir).
- Individu atau organisasi yang membutuhkan website/aplikasi mobile custom.
- Klien bisnis yang membutuhkan technical assistance dan pengembangan software.

## 3. Core Features
- **Hero Section**: Menampilkan value proposition dengan Call to Action (WhatsApp/Konsultasi).
- **Layanan**: Katalog layanan yang dapat diakses pengguna.
- **Keunggulan**: Nilai tambah layanan (Professional, Structured, Custom, Clear Communication).
- **Portfolio / Project Terpilih**: Showcase project sebelumnya.
- **Teknologi**: Tumpukan teknologi yang dikuasai.
- **Proses Kerja**: Alur pelayanan dari konsultasi hingga delivery.
- **FAQ**: Pertanyaan umum (Accessible Accordion).

## 4. Non-Functional Requirements
- **Performance**: Harus mencapai Lighthouse > 90.
- **Accessibility**: Mendukung keyboard navigation, ARIA attributes, semantic HTML.
- **Responsive**: Mendukung berbagai ukuran layar (320px hingga 1920px).
- **Architecture**: Modular HTML, CSS, Vanilla JS. Tidak membutuhkan build step.
